# LG Buddy KWin prebuilts

Immutable release assets for the [LG Buddy KWin bridge](https://github.com/Staphylococcus/LG_Buddy/tree/main/data/kwin/source). The index maps exact KWin/Qt build and loader-test inputs to archive locations and SHA-256 checksums. Each archive contains one portable plugin, metadata, and the loader verification record.

The [build and publication guide](https://github.com/Staphylococcus/LG_Buddy/blob/dev/docs/kwin-integration.md#building-and-checking-coverage) describes how maintainers build, verify, and publish these files. Install LG Buddy through its [normal releases](https://github.com/Staphylococcus/LG_Buddy/releases).
